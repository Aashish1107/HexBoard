HexBoard User Guide

Quick help for navigating the web application and completing common tasks.

Overview

This application lets you explore, edit, and visit hex-based maps. The main experience is split across a few pages so you can focus on one task at a time.

Home Editor Visit

Navigation Basics

  • Use the top navigation or the main buttons on the Home page to jump to a feature.
  • The browser Back button always returns you to the previous page.
  • If the page looks empty, scroll down for the main panel.

Home Page

The Home page is your starting point. It provides quick access to the Editor and Visit pages.

  • Choose Editor to create or modify a map.
  • Choose Visit to explore existing maps.

Editor Page

Use the Editor to design a hex map and adjust terrain or properties.

  • Select a map or start a new one.
  • Click a hex to view or change its properties.
  • Use the controls panel to set terrain, elevation, or other options.
  • Save your changes when you are done.

Visit Page

Visit mode is optimized for browsing and viewing maps.

  • Pick a map from the list.
  • Pan or zoom to inspect areas of interest.
  • Use any available filters to highlight features.

Common Tasks

Create a new map

  • Open the Editor.
  • Select the create option and name your map.
  • Fill in the hexes and save.

Open an existing map

  • Open the Visit page.
  • Select the map from the list.

Troubleshooting

  • If the page does not load, refresh the browser.
  • If a map does not appear, check that it exists in the list.
  • If changes are not saved, confirm you clicked the save button.
